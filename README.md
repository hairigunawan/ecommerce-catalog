🚀 Tugas Akhir – VIX Frontend Engineering (Inisiatif Inti)

Repositori ini berisi pengerjaan Tugas Akhir VIX Core Initiative – Frontend Engineering, di mana saya membangun halaman katalog produk e-commerce menggunakan Vue.js 2, Vanilla CSS, serta melakukan integrasi API berdasarkan brief yang diberikan.

📌 Tujuan Proyek

Pada tugas ini, saya bertanggung jawab untuk:

Website merancang halaman yang menarik berdasarkan komponen desain yang telah ditentuan.

Menghubungkan halaman website dengan API sehingga aplikasi dapat berjalan dengan optimal.

Mengimplementasikan seluruh fitur sesuai skenario dan requirement dari program.

🧩 Teknologi & Tools yang Digunakan

Vue.js 2

Vanilla CSS (tanpa kerangka kerja)

API Toko Palsu (https://fakestoreapi.com/
)

Git & GitHub untuk version control dan submission

Node.js versi terbaru

🔧 Fitur Utama

Fetch produk dari endpoint:
https://fakestoreapi.com/products/{index} (indeks = 1–20)

Tombol Next Product untuk menampilkan produk berikutnya (auto reset ke index 1 jika sudah mencapai 20)

Filteringkategori:
Menampilkan hanya produk kategori:

pakaian pria

pakaian wanita

Menggunakan class binding Vue untuk menerapkan desain berbeda:

Pria Halaman

Halaman-Wanita

Page-Unavailable untuk kategori lain

Penerapan variable CSS untuk color palette dari Figma

🎨 Desain Halaman

Terdapat 3 jenis layout:

Halaman Pakaian Pria

Halaman Pakaian Wanita

Halaman Produk Tidak Tersedia

Semua desain diimplementasikan menggunakan murni CSS tanpa framework.
